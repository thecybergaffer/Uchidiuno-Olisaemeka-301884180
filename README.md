Project Overview

This repository contains my practical portfolio for MIT 8103 Advanced Database Systems. 
It documents the design, implementation, testing and evaluation of SecFin (Secure Finance Wallet), a fictional digital wallet platform.

Portfolio Components

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Databases

Evidence and Documentation

SQL scripts, database diagrams, query execution plans, test results, screenshots and supporting documentation will be added progressively as each portfolio component is completed.

Case Study: SecFin

SecFin is a fictional digital wallet system designed to manage customer accounts, balances, deposits, withdrawals and transfers securely. 
The database will demonstrate relational database design, query optimisation, transaction integrity, NoSQL data modelling and distributed database concepts.

The system will also consider data integrity, transaction auditing and the needs of customer support staff, fraud analysts and auditors.
